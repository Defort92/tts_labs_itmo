# Результаты итоговой оценки

Этот каталог заполняется ноутбуком `lab4_fastspeech2_evaluation.ipynb`:

- `training_curves.csv`, `validation_curves.csv` и `loss_curves.png`;
- `test_metrics.json` — метрики на закрытом test split;
- `spectrogram_examples.csv` и `mel_*.png` — свободные предсказания модели.

Небольшие итоговые таблицы и изображения следует сохранить в Git вместе с
выполненным ноутбуком. Тяжёлые кэши F0/energy остаются в игнорируемом `data/`.
