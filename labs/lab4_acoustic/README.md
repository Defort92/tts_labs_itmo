# Лабораторная работа №4. Акустическая модель

## Постановка задачи

Обучить акустическую модель FastSpeech 2 для голоса RUSLAN. Модель получает
последовательность фонем и предсказывает mel-спектрограмму, длительности фонем,
высоту основного тона и энергию. В лабораторной №5 предсказанная
mel-спектрограмма будет преобразована вокодером в WAV.

Обучение находится в
[`lab4_fastspeech2_training.ipynb`](lab4_fastspeech2_training.ipynb), а
независимая итоговая оценка — в
[`lab4_fastspeech2_evaluation.ipynb`](lab4_fastspeech2_evaluation.ipynb).
Разделение сценариев защищает завершённое обучение от случайного повторного
запуска. В обучающем ноутбуке после завершения установлено
`RUN_TRAINING=False`.

## Входные данные и признаки

- `data/RUSLAN/RUSLAN/*.wav` — 22 050 Гц, mono, PCM16;
- `data/lab3_g2p/utterance_phonemes.csv` — последовательности фонем;
- `data/lab3_g2p/phoneme_alignments.csv` — временные границы фонем;
- `sil` используется как обычный входной токен паузы;
- mel-спектрограмма: 80 каналов, FFT 1024, окно 1024, шаг 256;
- `F0` и энергия вычисляются средствами курсового форка Coqui TTS.

Запись с приближённым выравниванием `005321_RUSLAN` исключается. Также
исключаются записи длиннее 15 секунд: это 255 выбросов (около 1,15% корпуса),
включая фрагменты до 50,7 секунды, непрактичные для Transformer-декодировщика на
8 ГБ VRAM. Все исключения сохраняются в `excluded.csv` с причиной. Для остальных
используется MFA-разметка из лабораторной №3.

## Метод

1. Проверить WAV и фонемные последовательности.
2. Один раз создать детерминированное разбиение 90/5/5 с `seed=42`.
3. При повторном запуске загрузить разбиение из кэша и проверить его целостность.
4. Перевести длительности фонем в целое число mel-кадров и создать one-hot
   attention masks для режима FastSpeech 2 без внутреннего aligner.
5. Проверить токенизацию многосимвольных MFA-фонем курсовым форком.
6. Выполнить двухэпоховый smoke test на 128/32 записях.
7. Только после успешного smoke test запустить полное обучение.

Обрезка тишины отключена: фонемные границы лабораторной №3 относятся к полному
WAV, поэтому обрезка изменила бы количество mel-кадров и разрушила длительности.

## Кэширование и защита от утечки

Разбиения сохраняются в `data/lab4_acoustic/splits/` и не попадают в Git.
Функция `create_or_load_splits()` проверяет:

- параметры разбиения и fingerprint исходных данных;
- отсутствие пересечений между train, validation и test;
- полное покрытие допустимых записей;
- отсутствие повторяющихся идентификаторов.

Если существующий кэш не соответствует данным, выполнение останавливается.
Пересоздание возможно только явно с `force=True` после проверки причины.
Тестовая выборка не передаётся `Trainer` и остаётся закрытой для итоговой оценки.

## Итоговая модель и оценка

Лучшим оказался checkpoint шага 742 028 (эпоха 298): validation loss
`1.498668`. Последняя эпоха дала `1.550545`, поэтому для дальнейших работ
используется не последний, а лучший по validation вариант.

Checkpoint и исходная конфигурация находятся в `artifacts/`. Файл модели имеет
размер около 431 MiB и хранится через Git LFS; его SHA-256 и критерий выбора
зафиксированы в `artifacts/model_manifest.json`. Итоговый notebook:

1. восстанавливает кривые обучения с учётом перезапусков;
2. считает loss-компоненты на всех 1093 закрытых test-записях;
3. выполняет свободный inference для трёх детерминированно выбранных примеров;
4. сохраняет таблицы и изображения в `results/`.

Полный проход по 1093 test-записям дал общий teacher-forced loss `1.105759`:
`loss_spec=0.968377`, `loss_dur=0.035736`, `loss_pitch=0.050510`,
`loss_energy=0.051136`, средняя ошибка длительности — `3.508833` mel-кадра на
фонему. Test loss на 26,22% ниже лучшего validation loss. Это не доказывает, что
test проще во всех отношениях, но показывает отсутствие ухудшения на отложенных
данных; разницу следует интерпретировать осторожно, поскольку наборы содержат
разные аудиозаписи.

Свободный inference выявил ограничение, которое teacher-forced loss скрывает:
для трёх фиксированных примеров предсказанная длительность составляет только
64,5–81,9% эталонной. Предсказанные спектрограммы также заметно более сглажены и
теряют часть тонкой гармонической структуры. Следовательно, модель усвоила
общий спектральный контур, но склонна ускорять длинные фразы и усреднять детали.
Окончательно воспринимаемое качество можно оценить только после подключения
вокодера и прослушивания в лабораторных №5–6.
