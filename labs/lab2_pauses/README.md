**Лабораторная работа №2. Просодика**

> Основной файл для просмотра и сдачи по требованиям курса: [`lab2_prosody.ipynb`](lab2_prosody.ipynb). Блокнот содержит постановку задачи, описание входных признаков, метод, анализ разметки, сравнение с baseline, метрики и выводы.

В текущей версии исходного задания заявлены две цели:

1. предсказание мест пауз в речи и их длительности по тексту;
2. разметка корпуса по словам.

Зависимости устанавливаются из корня репозитория:

```powershell
.\.venv\Scripts\python.exe -m pip install -r labs\lab2_pauses\requirements.txt
```

## Реализация

`align_words.py` выполняет forced alignment нормализованного текста из
лабораторной №1 и аудио RUSLAN с помощью русскоязычной CTC-модели Wav2Vec2.
Результат сохраняется в общей CSV-таблице и в TextGrid для ручной проверки.
Текст из ASR не подменяет эталон: выравнивается именно проверенная строка из
`metadata_RUSLAN_22200_normalized.csv`.

Пилотный запуск:

```powershell
.\.venv\Scripts\python.exe labs\lab2_pauses\align_words.py --limit 10
.\.venv\Scripts\python.exe labs\lab2_pauses\extract_pauses.py
.\.venv\Scripts\python.exe labs\lab2_pauses\make_review_set.py
```

После первого скачивания модели можно добавить `--offline`, чтобы полностью
отключить сетевые проверки Hugging Face.

Полный возобновляемый запуск (уже записанные строки не обрабатываются повторно):

```powershell
.\.venv\Scripts\python.exe labs\lab2_pauses\align_words.py --offline --resume --device cuda --dtype float16 --batch-size 16 --max-batch-mb 4.5 --sort-by-duration
```

Для компьютера без CUDA используются `--device cpu --dtype float32 --batch-size 1`.
Ограничение `--max-batch-mb` автоматически уменьшает пакет для длинных WAV и
предотвращает переполнение памяти GPU.
Режим FP16 проверен относительно FP32 на контрольной выборке: слова совпали,
а максимальное смещение временной границы составило один кадр (около 20 мс).

Результаты создаются в `data/lab2_pauses/`:

- `word_alignments.csv` — начало, конец и уверенность для каждого слова;
- `alignment_status.csv` — успешные и ошибочные записи;
- `textgrids/*.TextGrid` — разметка для проверки в Praat;
- `pause_boundaries.csv` — признаки и длительность каждой границы между словами.
- `review_clips/` — короткие WAV-фрагменты и чек-лист ручной проверки.

Обучение и применение текстовой модели после полной разметки:

```powershell
.\.venv\Scripts\python.exe labs\lab2_pauses\extract_pauses.py
.\.venv\Scripts\python.exe labs\lab2_pauses\analyze_pause_data.py
.\.venv\Scripts\python.exe labs\lab2_pauses\train_pause_model.py
.\.venv\Scripts\python.exe labs\lab2_pauses\predict_pauses.py "Это первая часть, а это вторая."
```

`train_pause_model.py` сравнивает модель с пунктуационным baseline. Для наличия
паузы выводятся precision, recall и F1, для длительности — MAE в миллисекундах.
MAE регрессии сравнивается с константным baseline — медианной длительностью пауз
на обучающей части. Разделение выполняется по идентификаторам аудиозаписей.

Порог паузы зафиксирован равным 80 мс после пилотного анализа распределения:
более короткие низкоэнергетические участки чаще соответствуют межсловным
переходам, а не воспринимаемой паузе. Акустический порог составляет −40 dBFS
на кадрах длиной 10 мс. Для дополнительной ручной проверки сформирован
стратифицированный набор фрагментов и чек-лист в `review_clips/`.

## Результаты полного корпуса

- выровнено 22 100 из 22 100 фраз, ошибок нет;
- размечено 254 972 слова и 232 872 межсловные границы;
- обнаружена 48 561 пауза (20,85% границ), медиана — 209,5 мс;
- пунктуационный baseline: F1 = 0,7166;
- текстовая модель: F1 = 0,7423;
- baseline длительности: MAE = 116,6 мс;
- Ridge-регрессия длительности: MAE = 102,6 мс.

Метрики рассчитаны на отложенных фразах: порог классификации выбран только на
валидационной части, тестовая часть при выборе порога не использовалась.
